My Planner 2027 ♡

ชุดไฟล์ต้นแบบ PWA สำหรับ Android
- เปิดใช้งานผ่านเว็บไซต์ที่ให้บริการ HTTPS
- เปิด URL ด้วย Google Chrome บน Android
- แตะเมนู ⋮ > เพิ่มลงในหน้าจอหลัก (Add to Home screen) หรือ Install app
- หลังเปิดครั้งแรกและแคชไฟล์แล้ว สามารถใช้งานออฟไลน์ได้
- ข้อมูลเก็บใน Local Storage ของเบราว์เซอร์เครื่องนั้น
- ใช้ปุ่ม “สำรองข้อมูล” ในหน้า Annual Summary เพื่อดาวน์โหลด JSON และเก็บสำรอง

ข้อสำคัญ:
ไฟล์ ZIP นี้ยังไม่ใช่ APK และยังไม่สามารถติดตั้งจาก ZIP โดยตรงได้
ต้องนำไฟล์ไปเผยแพร่บนโฮสต์ HTTPS ก่อน เช่น GitHub Pages
ข้อมูลไม่ซิงก์ข้ามเครื่องโดยอัตโนมัติ ควรสำรองข้อมูลเป็นระยะ
